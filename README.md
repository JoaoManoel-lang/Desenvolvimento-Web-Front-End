# 🎸 Projeto Rock BSB Roll — Site Oficial do Evento

## 🎯 Objetivo do Projeto

Criar uma página web moderna e interativa para divulgar o evento **Rock BSB Roll**, promovido na Esplanada dos Ministérios em Brasília. O projeto tem como foco oferecer uma experiência digital envolvente para os visitantes, com informações sobre o evento, venda de ingressos, formulário de opinião, e identidade visual alinhada ao universo do rock.

---

## ⚙️ Descrição das Funcionalidades

- **Página principal com identidade visual temática**, incluindo cores escuras, fontes estilizadas e elementos gráficos que remetem ao rock.
- **Seção de ingressos** com opções de compra e exibição dinâmica do carrinho.
- **Formulário de opinião** para coleta de sugestões e feedbacks dos visitantes.
- **Página de agradecimento personalizada**, exibida após o envio do formulário.
- **Layout responsivo**, adaptado para dispositivos móveis e desktops.
- **Navegação fluida** com seções bem definidas e chamadas visuais.

---

## 🧪 Tecnologias Utilizadas

- **HTML5** — estrutura semântica das páginas e componentes.
- **CSS3** — estilização visual com foco em contraste, tipografia e responsividade.
- **JavaScript (Vanilla)** — controle de interações como envio de formulário, exibição de carrinho e redirecionamentos.
- **Fontes personalizadas** — uso da fonte *Oswald* para reforçar a estética urbana e musical.
- **FormSubmit (opcional)** — integração para envio de dados via e-mail, se desejado.

---

## 🚀 Instruções para Execução do Projeto

1. **Baixe ou clone os arquivos** do projeto para uma pasta local.
2. Certifique-se de que os seguintes arquivos estejam presentes:
   - `index.html` — página principal com todas as seções.
   - `agradecimento.html` — página exibida após envio do formulário.
   - `style.css` — arquivo de estilos (se estiver separado).
   - Imagens e fontes utilizadas no layout.
3. **Abra o arquivo `index.html`** em um navegador moderno (Chrome, Edge, Firefox).
4. Navegue pelas seções, preencha o formulário e clique em **Enviar**.
5. Você será redirecionado automaticamente para `agradecimento.html`.
